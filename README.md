# RuCutz Premium Grooming — website

Marketing site + booking-portal preview for **RuCutz Premium Grooming** (Heru "Ru" Ward), a private-suite barber in Salon Lofts Hollywood, Loft 13, Hollywood, FL.

Built by Couture House Co. Next.js 16 (App Router) · TypeScript · Tailwind v4 · GSAP/ScrollTrigger · Lenis · static export.

---

## Quick start

```bash
npm install            # do this OUTSIDE OneDrive (see "OneDrive" below)
npm run dev            # http://localhost:3000
npm run build          # static export to ./out
npm run serve          # serve ./out at http://localhost:4321
```

## The audit (run before anything is shown to the client)

```bash
npm run audit          # lint → build → contrast → content/SEO → accessibility
npm run audit:contrast # every colour pairing measured against WCAG AA
npm run audit:flow     # built HTML vs the data files: links, SEO tags, prices, NAP, schema
npm run audit:a11y     # axe-core at 375 / 768 / 1024 / 1440 + tap targets + overflow
npm run frames         # full-page screenshots of every route into .frames/
```

`audit:a11y` and `frames` need the static server running (`npm run serve` in another shell) and a Chromium binary; set `PW_CHROMIUM=/path/to/chromium` if Playwright's default download isn't present.

## How the site is put together

```
src/data/          The single source of truth. Change facts HERE, never in a component.
  business.ts        NAP, hours, booking URL, social links, policies
  services.ts        All 14 services with Ru's real prices, durations and inclusions
  faqs.ts            Answer-first FAQ copy (feeds the page and FAQPage schema)
  reviews.ts         Verbatim Google reviews
  journal.ts         The three long-form guides
  photos.json        Generated by scripts/process_images.py — do not hand-edit
src/lib/           schema.ts (JSON-LD), meta.ts (per-page SEO), hours.ts (open/closed),
                   photos.ts, db.ts (DEMO data layer for the booking portal)
src/components/    UI. `home/` holds the homepage sections.
scripts/           Image pipeline + the three audits + frame grabber
public/img/        Pre-generated WebP renditions (1200w / 720w, hero 1600/960/560)
public/brand/      Ru's logo, scissors mark and ankh, vectorised from his own artwork
```

### Booking

Every "Book" CTA points at Ru's **live Square Appointments page** (`BOOKING_URL` in `src/data/business.ts`), so the site takes real bookings from day one.

`/book/` and `/portal/` are a **preview** of the custom portal we can build next: a five-step booker with a live running total and hours-aware availability, and an owner dashboard with a rebook radar and client photo journeys. Both run on typed mock data in `src/lib/db.ts` and are marked as previews on screen and `noindex` in metadata. Going live is a backend swap behind that one file (see the `// TODO:` seams).

### Images

`npm run images` regenerates `public/img/` and `src/data/photos.json` from the raw source photos. The raw folder is not in the repo (it holds the untouched Instagram/Yelp downloads); the curated list, crops and alt text live in `scripts/process_images.py`.

## Deploying

Static export, so anything that serves files works.

**Netlify (recommended)** — build command `npm run build`, publish directory `out`, Node 20+.
**Vercel / Cloudflare Pages** — same settings.

Then point `rucutzpremiumgrooming.com` at it and turn off the old Square Online site. Add a redirect for the old paths if any are indexed:

```
/s/appointments   /services/   301
/contact-us       /visit/      301
```

## OneDrive

Never run `npm install` inside the OneDrive-synced folder: npm hangs and git cannot unlink its lock files. Copy the repo somewhere local (or clone it from GitHub) before installing.
